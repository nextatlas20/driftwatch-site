Contribute

How to contribute to Driftwatch, from your first branch to the final review.

  1. Create a branch

    Create a branch named feat/<short-slug> for new features, or fix/<short-slug> for bug fixes.

  2. Run the test suite

    Run the test suite with pytest -q before opening a pull request.

  3. Update the documentation

    Documentation changes live under docs/ and need a preview build.

  4. Follow the Code of Conduct

    Report Code of Conduct concerns to conduct@driftwatch.org.

  5. Pick a good first issue

    Issues labelled good first issue are reserved for new contributors.

  6. Get a review

    Every pull request needs approval from one maintainer before it is merged.

Driftwatch is an open-source project hosted by the Coastline Data Trust.

Driftwatch

Turning satellite pixels into shoreline decisions

Driftwatch is an open-source Python toolkit for monitoring coastal erosion from satellite imagery. The project is hosted by the Coastline Data Trust, a nonprofit based in Portland, Oregon.

Focus areas

  • Shoreline change detection

    Shoreline change detection from multi-temporal satellite imagery.

  • Tidal inundation forecasting

    Tidal inundation forecasting for coastal planners.

  • Community-science data validation

    Community-science data validation with local volunteer groups.
